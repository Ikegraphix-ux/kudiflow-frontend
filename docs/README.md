# KudiFlow Documentation

This folder contains the supporting technical documentation for the KudiFlow frontend prototype.

## Documents

| Document | Purpose |
|---|---|
| [Architecture](architecture.md) | Current frontend architecture and planned backend architecture |
| [Technical Decisions](technical-decisions.md) | Important implementation choices and their reasoning |
| [Testing](testing.md) | Manual test cases and expected results |

## Documentation Principle

The documentation distinguishes between:

- **Implemented** — behavior currently present in this repository
- **Simulated** — behavior represented with browser storage or mock data
- **Planned** — backend or production capabilities intended for a future phase

This distinction keeps the project technically honest and makes future backend integration easier to understand.
